## 1.0.281 — 15 November 2026

Added
- **SNMP: everything the application can tell, typed** (OTP-MIB, `.7.10`-`.7.17`): the machine (CPU time idle and in all, cores, the load, memory and swap, bytes read and written by the disks and by the network cards - counters, a rate is the monitor's to make; uptime; the file systems otp lives on with size, used, free, % and inodes), RADIUS (the clients, realms and directories set; accepted, rejected and challenged in the last 24 hours and a table of every result), each directory and whether it answers this node, the cluster (whether this node holds the VIP address, the replication both ways), the nightly copy and the backups sent away, the mail queue, the ways of signing in to the administration with the CRLs and OCSP answers, the clock guard, the logs sent to isemon and a SIEM. Each part answered by itself: one that fails leaves the others answered. OTP-MIB has every object in a conformance group (smilint and net-snmp take it without a word).
- **Zabbix 7.0: the template "otp by SNMP"**, to download on *Settings → Monitoring → SNMPv3* (with OTP-MIB) and in `deploy/zabbix/`: items for every object, discovery of the tables (each problem otp sees a problem of its own in Zabbix while it lasts, the certificates, the nodes, the file systems, the directories, the replication, the RADIUS results), triggers with their limits as macros, value maps, graphs and a dashboard of five pages (*Overview*, *RADIUS*, *Machine*, *Cluster and directories*, *Certificates, sign-in, backups*). docs/monitoring.md: the objects and how to put a node into Zabbix.
